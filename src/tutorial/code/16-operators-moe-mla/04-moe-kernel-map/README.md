# 04-moe-kernel-map · MoE 引用的行号核对

**目的**：把本章 MoE 部分的每条源码引用写成“文件:行号”，并**实际打开文件检查
那一行是否包含我引用的 token**。锁定版本不动，所以这个检查可重复。

**运行前提**：Python 3.9+，纯标准库；需要 `_vendor/` 存在才能核对（不存在时跳过）。

**运行命令**

```bash
python3 kernel_map.py
python3 kernel_map.py --book ../../..
```

**预期输出**

每行形如 `ok examples/...:NN (token)`；末尾打印 `合计：36 处命中，0 处未命中。`
若有 `FAIL`，说明本章引用与锁定版本不符，必须修正文或修引用。

**作者实际做到的验证级别**：`CPU 逻辑验证`（实际运行过，36/36 命中）。
这是一个**引用完整性检查**，不是正确性证明。
