# 02-abstraction-layers — 可运行的坐标系

## 目的

把第 05 章的「抽象层次表」和「决策表」编码成一个**纯 Python、无第三方依赖**的脚本，
方便你在读正文时随手查、也方便把它当练习（E14）的起点。

## 运行前提

* Python 3.10+；**不需要 GPU/NPU**，不需要联网，不需要安装任何包。

## 运行命令

```bash
python3 abstraction_layers.py
```

## 预期输出

脚本会打印三块内容：

1. 七个对象的抽象层次表（层次 / 用户写什么 / 编译器替你做什么 / 与 TileLang 的关系）；
2. 三层抽象的定义与每个对象所属层级；
3. 一个交互式的 `choose()` 示例：按「硬件 → 目标是算子还是编译器 → 让出多少控制权」
   给出候选工具，并打印它依据的是本章哪条证据编号。

它**不产生任何性能结论**，也不依赖任何实测数据。

## 验证级别

`在 CPU 上验证过逻辑`：纯 Python，作者在本机运行并通过（无硬件、无网络依赖）。
