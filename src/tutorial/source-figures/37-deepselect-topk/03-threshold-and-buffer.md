# 图 3：阈值单调上升，候选缓冲区有界振荡

**用途**：正文 §2.4。

数据来源：本章示例 `code/01-deepselect-python/deepselect_python.py --trace`
在一次随机输入（`N=262144, k=512, B=B2=1024`）上的运行输出。它是**算法计数**，
不是 kernel 测量。

```text
扫描进度   阈值 T        候选缓冲区
  0%       −∞            1024
 10%       0.9754         648
 27%       0.9919         631
 45%       0.9919        1033
 72%       0.9972         550
100%       0.9972         712     （最终 compact 后 → 512）
```

## 读图提示

* `T` 在这段采样里从 `−∞` 单调升到 `0.9972`，**从不回落**。
* 候选缓冲区在 `k`（512）与 `k+B2`（1536）附近来回，实测最大值 `2048 = k+B2+B`，
  正好顶着报告给的上界（`.../DeepSelect/docs/DeepSelect-deep-dive.zh.md:47`）。
* 柱长读**候选缓冲区元素数**，标注读**阈值**：柱长在振荡、阈值在单调上升，
  两件事要一起看。
* 「增长越来越慢」是**接受率**在下降，6 个采样点看不出来；完整的逐块轨迹见
  `code/01-deepselect-python/README.md` 的 `--trace` 输出。
