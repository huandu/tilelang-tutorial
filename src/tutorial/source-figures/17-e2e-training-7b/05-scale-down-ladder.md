## 图 5 · 按比例缩小的降级路径

对应正文 §10。7B 全量训练单机做不了，所以本教材不要求你一步到位，而是给一个
**可以逐级验证**的阶梯：每一级都小到能在一台机器上跑完，且每一级都复用上一级的
代码与验收标准。

```mermaid
flowchart TB
    L0["L0 · 冒烟<br/>~0.1M 参数 · 内置语料<br/>目标：一步能跑通，loss 有限<br/>CPU · 秒级"]
    L1["L1 · 字符级 / 小 BPE<br/>~10M~125M · TinyStories<br/>目标：100 步 loss 下降、开始收敛<br/>1×GPU · 分钟~小时"]
    L2["L2 · 0.5B 继续训练<br/>Qwen2.5-0.5B · 领域语料<br/>目标：与 HF 参考数值对齐<br/>1×GPU（20~40GB）"]
    L3["L3 · 1.5B / 3B<br/>同族结构放大<br/>目标：跑通多卡 + 分片 + 恢复<br/>2~8×GPU"]
    L4["L4 · 7B<br/>Qwen2.5-7B · 小规模继续训练<br/>目标：吞吐/显存达标，loss 稳定<br/>8~64×GPU（ZeRO-3/FSDP）"]

    L0 --> L1 --> L2 --> L3 --> L4
```

**读图要点**

* 阶梯的**升阶条件**：每级都要先满足“数值与 HF 参考对齐”再往上走，
  否则你会发现放大后无法定位是数据、模型还是 kernel 的问题。
* 每级的 `显存 / 时间` 都用 §2 的账本方法估：把该级的参数量代入
  `train_plan.py`（`--tokens` 与 `--eff-tflops` 用该级的真实值）。
* L2 起就必须处理分片（FSDP/ZeRO）与 `torchrun`；L0/L1 不需要。
* 昇腾把 L2~L4 的算子路径换成 `target="ascend"`（§8），但阶梯本身不变。
